A tiny Python program that writes one line to /output/entry.txt for make.fun's One Star for Monday bounty: a one-star review of Monday, written as though Monday were a restaurant. The line is a fixed string, so every run writes the same bytes.

> One star. Booked a table for the weekend, got seated at 7 a.m. on Monday, and the waiter charged me for all five days.

## Run it

```sh
python3 main.py
```
